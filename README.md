# CodeCraft

A simple command-line calculator that computes **Simple Interest** and the total amount.

## Formula

\[
SI = \frac{P \times R \times T}{100}
\]

Where:
- **P** is the principal amount
- **R** is the annual rate of interest (percentage)
- **T** is the time in years

**Total Amount = Principal + Simple Interest**

## Requirements
- Bash
- awk (usually pre-installed on Linux and macOS)

## Run

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Enter the principal, annual interest rate, and time when prompted. The script displays the simple interest and total amount.

## Example

For principal 1000, rate 5, and time 2 years:
- Simple interest: 100
- Total amount: 1100
